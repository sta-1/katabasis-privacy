Backend'i kazdım. Analiz işi burada yapılıyor:

C:\Users\yetim\OneDrive\Desktop\ruya-arsivi\backend\routes\analyze.js

Uygulama rüyayı mobil taraftan backend'e gönderiyor, backend de Anthropic Claude API ile analiz üretiyor.

Akış net olarak şöyle:

1. Mobil uygulama şuraya POST atıyor:

/api/analyze

2. Backend dream alanını alıyor:

const { dream } = req.body;

3. Rüya metni kontrol ediliyor:

- 10 karakterden kısaysa reddediyor.
- 3000 karakterden uzunsa reddediyor.

4. Sonra Anthropic'e şu modelle istek atıyor:

model: "claude-sonnet-4-5"

5. Claude'a sabit bir sistem prompt'u veriliyor. Bu prompt Claude'a şunu söylüyor:

- Carl Gustav Jung yaklaşımıyla analiz yap
- Arketipleri açıkla
- Kolektif bilinçdışı / kişisel bilinçdışı yorumla
- Sembolleri açıkla
- Bilinçdışı mesajı çıkar
- İndividüasyon açısından değerlendir
- 3-4 yansıma sorusu ver
- Türkçe, şiirsel ve derin yaz
- Markdown kullanma

6. Kullanıcının rüyası Claude'a şöyle gönderiliyor:

messages: [{ role: "user", content: `Rüyam: ${dream}` }]

7. Claude'dan gelen cevap alınır:

const text = message.content[0].text;

8. Mobil uygulamaya şu şekilde geri döner:

res.json({ text });

Yani backend'in "rüya analizi" yapma gücü aslında şu üç şeyden geliyor:

- Kullanıcının yazdığı rüya metni
- Backend'de yazılmış Jung odaklı detaylı prompt
- Anthropic Claude modeli

• Evet, kesinlikle maliyeti var. Bu uygulamada ana değişken maliyet Anthropic Claude API token maliyeti.

  Şu an backend’de kullanılan model:

  claude-sonnet-4-5

  Resmi Anthropic fiyatına göre Claude Sonnet 4.5:

  - Input: $3 / 1 milyon token
  - Output: $15 / 1 milyon token

  Kaynak: Anthropic Claude pricing: https://docs.claude.com/en/docs/about-claude/pricing

  Senin endpoint’te ayrıca şu sınır var:

  max_tokens: 2500

  Yani Claude’un üreteceği cevap en fazla yaklaşık 2500 token olabilir. Kullanıcının rüya metni de en fazla 3000
  karakter.

  Kabaca tek analiz maliyeti şöyle olur:

  Maliyet = input token * 0.000003 USD
          + output token * 0.000015 USD

  Gerçekçi örnek:

  Input:
  - Jung sistem prompt'u
  - Kullanıcının rüyası
  Yaklaşık: 1500-2500 token

  Output:
  - Rüya analizi
  Yaklaşık: 1000-2000 token

  Yaklaşık maliyet:

  2000 input token  = $0.006
  1500 output token = $0.0225

  Toplam = $0.0285

  Yani bugünkü yapıyla tek rüya analizi yaklaşık 2-5 cent arası tutar. Daha uzun cevaplarda 5 cent’e yaklaşır; kısa
  rüyalarda ve kısa analizlerde 2-3 cent civarı kalır.

  Daha pratik ürün hesabı:

  1 kullanıcı ayda 10 analiz yaparsa:
  10 * $0.03 = $0.30

  1 kullanıcı ayda 30 analiz yaparsa:
  30 * $0.03 = $0.90

  1000 kullanıcı ayda 10 analiz yaparsa:
  10.000 analiz * $0.03 = $300

  Ama bizim konuştuğumuz uzun vadeli “bilinçdışı günlüğü / örüntü keşfi” yönüne gidersek maliyet artar. Çünkü sadece tek
  rüyayı değil, geçmiş rüyaları da modele vermeye başlarız.

  Mesela:

  Son 30 rüyadan aylık rapor:
  20.000 input token + 1500 output token

  Input: 20.000 * $0.000003 = $0.06
  Output: 1500 * $0.000015 = $0.0225

  Toplam = $0.0825

  Yani aylık derin rapor gibi özellikler analiz başına değil, rapor başına 8-15 cent bandına çıkabilir.
